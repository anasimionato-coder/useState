# Atividade 1 — Primeiros passos com useState

Projeto React (Vite + JavaScript) com exercícios de estado usando `useState`.

## Conteúdo

- Missão 1: contador com botões "Aumentar" e "Voltar um"
- Missão 2: mostrar e esconder um aviso (estado booleano)
- Missão 3: saudação com campo de texto controlado
- Desafio final: cartão de boas-vindas
- Desafio extra: contador com meta 10 e botão de zerar

## Como rodar

    npm install
    npm run dev

## Verificações

    npm run lint
    npm run build
